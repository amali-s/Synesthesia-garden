# Synesthesia Garden

A pixel-art meadow that grows from **vocal pitch**.

## Features

- **Listen** — microphone pitch grows flowers in real time
- Higher pitch deepens hue and saturation
- Quiet pauses sprout grass

Upload, playback, and streaming links (Spotify / Qobuz) are hidden for now.

## Develop

```bash
npm install
npm run dev
```

No API secrets are required.

## Deploy

**GitHub Pages** or **Vercel** both work for the current voice garden.

## Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Vite dev server |
| `npm run build` | Typecheck + production build |
| `npm run preview` | Preview the production build |
